{# Phosphor icon sprite (https://phosphoricons.com, MIT). Inlined rather than pulled from a CDN or loaded as an icon font: only a handful of icons are used, the whole sprite is a few KB, and it means the UI renders identically with no network round-trip and no flash of unstyled icons. Icons inherit the surrounding text colour via fill="currentColor". Usage in a template: Usage from JS: icon('brain') (see static/icons.js) In an alert summary: iconifySummary(text) (see static/icons.js) NOTE: web UI only. Telegram messages, plain-text email and server logs cannot render SVG, so those surfaces keep their emoji on purpose — see the comment on scanner.build_summary(). iconifySummary() is what bridges the two: the summary string is authored once with emoji and swapped to Phosphor at render time in the browser. #}
